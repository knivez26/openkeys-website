OPENKEYS WEBSITE + VISUAL TUTORIAL

Open index.html in any modern browser to view the public OpenKeys landing page. Choose Manual to open the phone/tablet guide selector. The complete site is self-contained and does not need a build step.

Open tablet.html for the dedicated tablet edition with persistent chapter navigation and tablet-sized reading panels.

Files:
- index.html: public OpenKeys landing page
- manual.html: phone/tablet selection screen
- guide.html: complete responsive tutorial
- tablet.html: tablet-first tutorial entry point
- 404.html: branded missing-page experience
- assets/css: responsive visual design
- assets/js: navigation, search, reading progress, and interactions
- assets/screenshots: captured OpenKeys interface images

GitHub Pages publishes this folder through .github/workflows/pages.yml. CNAME configures the production domain as openkeys.pro.
